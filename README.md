🌍 The State of the World's Children — Data Dashboard
An independent, interactive data dashboard exploring child welfare across 71 countries:nutrition, education, immunization, survival, youth happiness — and a responsibly-framedyouth mental health module with per-country male/female analysis, root causes,prevention strategies, helplines, and 2030 projections.

✨ Features
7 interactive visualizations (Chart.js) with animated stat cards
2030 stunting forecast via least-squares linear regression (implemented from scratch)
k-nearest-neighbors "statistical twins" similarity search (5 normalized features)
Auto-generated per-country action plans based on severity scoring
Progress simulator with illustrative intervention modeling
Youth mental health crisis module following WHO responsible-reporting guidance
Per-country male & female risk-factor analysis and verified helplines
🛠 Tech
HTML · CSS · Vanilla JavaScript · Chart.js — zero frameworks, zero build step, single file.

📊 Data
Approximate values compiled from UNICEF/WHO/World Bank estimates (2000–2022),rounded for readability. Verify before citing. Helplines change — see findahelpline.com.
